PostgreSQL Ovelsessamling

En samling af 20 praktiske PostgreSQL ovelser designet til undervisning i databaseadministration, optimering og udvikling. Hver ovelse er selvforsynende med Docker og kan kores lokalet.

Forudsatninger

  • Docker Desktop eller Podman
  • Minimum 8 GB RAM (16 GB anbefalet til avancerede ovelser)
  • Grundlagende kendskab til SQL og terminal

Ovelser

  • 01: Kanariefuglen i kuldemineren
    Let 30-45 min Performance tuning med pgbench
  • 02: Statistik er ikke et fyord
    Let 30 min ANALYZE og query-planlagning
  • 03: At lasse en eksekveringsplan er at lasse poesi
    Let 45 min EXPLAIN, Seq Scan, Nested Loop, Hash Join
  • 04: Indeksokonomi: fart er ikke gratis
    Let 45 min Indekser og skriveperformance
  • 05: Datamodellederens anger
    Middel 60 min Normalisering og denormalisering
  • 06: pg_stat_activity som reality show
    Middel 45 min Overvagning af aktive forbindelser
  • 07: Journalterminalen: JSON uden dom
    Middel 60 min jsonb vs relationel modellering
  • 08: VACUUM dagbogen
    Middel 45 min Bloat, autovacuum og VACUUM FULL
  • 09: Transaktionsteateret
    Middel 60 min Isolationsniveauer: READ COMMITTED, REPEATABLE READ, SERIALIZABLE
  • 10: Dodlasens koreografi
    Middel 45 min Deadlocks med to sessioner
  • 11: Koedisciplin: lock_timeout som moral
    Middel 45 min Lock timeout og backoff
  • 12: Adgangskontrollens cirkulare beslutning
    Middel 45 min Roller, grants og tilladelsesgraf
  • 13: Hukommelsesoekonomen under pres
    Middel 45 min work_mem, sortering og disk spill
  • 14: Extensionsbiografen: kobe eller bygge?
    Middel 60 min pg_trgm, pgcrypto, PostGIS
  • 15: Forbindelsespoolens ventevaerelse
    Svar 60 min PgBouncer og connection pooling
  • 16: At partitionere fortiden
    Svar 60 min Deklarativ partitionering
  • 17: Backuppens vaerdi er nul, indtil den er testet
    Svar 75 min WAL arkivering, PITR
  • 18: En haer af trofaste kopier
    Ekspert 75 min Primary + replika, failover
  • 19: Den store migration
    Ekspert 75 min Major version upgrade
  • 20: Den langsomme app: et afsluttende mordmysterium
    Ekspert 90 min Integreret diagnoseovelese

Brug

Klor repositoryet og naviger til den onskede ovelse: 

git clone https://github.com/andracs/postgres-sec-exercises.git
cd postgres-sec-exercises/oevelser/01-kanariefuglen
docker compose up -d
# Vent pa database
docker compose exec postgres pg_isready -U studie
# Følge instruktioner i OEVELSE.md
# Ryd op
docker compose down -v

Login

Alle ovelser bruger: studie/studie/studiebase på localhost:5432
