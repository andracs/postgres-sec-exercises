PostgreSQL Øvelsessamling

En samling af 13 praktiske PostgreSQL-øvelser til undervisning i databasesikkerhed, -administration og -optimering. Hver øvelse er selvforsynende med Docker og kan køres lokalt.

Forudsætninger

  • Docker Desktop eller Podman
  • Minimum 8 GB RAM
  • Grundlæggende kendskab til SQL og terminal
  • openssl og psql på hosten (kun øvelse 13)

Øvelser

Sikkerhedsaspekt: CIA = fortrolighed/integritet/tilgængelighed (C/I/A). NIST = kontrolfamilier i NIST SP 800-53 (AU=audit, AC=adgangskontrol, SC=kryptering/kommunikation, CP=backup, SI=integritet, IA=identifikation).

  • 01: Benchmarking og hukommelseskonfiguration med pgbench
    CIA-A · ressource/DoS Let 30-45 min Performance-tuning med pgbench og konfiguration
  • 02: Statistik og ANALYZE til bedre query-planer
    — fundament Let 30 min ANALYZE og query-planlægning
  • 03: Læsning af eksekveringsplaner med EXPLAIN
    — fundament Let 45 min EXPLAIN, Seq Scan, Nested Loop, Hash Join
  • 04: Indekser: hurtigere læsning, langsommere skrivning
    CIA-A · skrive-DoS Let 45 min Indekser, læse- vs skriveperformance
  • 05: Normalisering til 3NF og bevidst denormalisering
    CIA-I · dataintegritet Middel 60 min Normalisering, denormalisering
  • 06: Overvågning af forbindelser og queries med pg_stat_activity
    NIST AU · overvågning Middel 45 min Overvågning af aktive forbindelser
  • 07: Logging og audit af databaseaktivitet
    NIST AU-2/AU-9 · audit & log Middel 45 min PostgreSQL-log, log_statement, fejlfinding
  • 08: Brugeradministration og rettigheder (roller, GRANT/REVOKE, RLS)
    NIST AC-3/AC-6 · least privilege, RLS Middel 45 min Roller, GRANT/REVOKE, Row Level Security
  • 09: Transaktioner, isolation og savepoints
    CIA-I · NIST SI-7 (ACID) Middel 60 min ACID, isolationsniveauer, to sessioner
  • 10: Triggers og audit-log
    NIST AU+SI · audit via triggers Middel 45 min Trigger-funktioner, BEFORE/AFTER
  • 11: Kryptering med pgcrypto
    CIA-C · NIST SC-28 (kryptering i hvile) Middel 45 min pgp_sym_encrypt, password-hash med crypt
  • 12: Backup og point-in-time recovery (PITR)
    NIST CP-9/CP-10 · backup/PITR (CIA-A) Svær 75 min pg_basebackup, WAL-arkivering, recovery_target_time
  • 13: TLS på forbindelsen og secrets management
    NIST SC-8 TLS · IA-5 secrets (CIA-C) Svær 60 min SSL-certifikater, pg_hba hostnossl, Docker secrets

Brug

Klon repositoryet og naviger til den ønskede øvelse: 

git clone https://github.com/andracs/postgres-sec-exercises.git
cd postgres-sec-exercises/oevelser/01-kanariefuglen
docker compose up -d
# Vent på database
docker compose exec postgres pg_isready -U studie
# Følg instruktionerne i OEVELSE.md
# Ryd op
docker compose down -v

Login

Øvelse 01-12 bruger: studie / password studie / database studiebase på localhost:5432.
Øvelse 13 (TLS/secrets) henter password fra Docker secret — se secrets/db_password.txt efter ./scripts/setup.sh.
