# DroneTransport Næstved — praktisk test (60 min)

1. Udpak og start casen:
   ```bash
   docker compose up -d
   ```
2. Læs `opgavebeskrivelse.md` — där står hele opgaven og tidsrammen.
3. Udfyld `afleveringsskabelon.md` og aflever sammen med dine SQL/kommandoer.

⚠️ Kun lokalt Docker-lab. Alle data er syntetiske. Casen er bevidst usikker — det er opgaven at finde ud af hvorfor.
