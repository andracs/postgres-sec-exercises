# Bedømmelsesrubrik (5 kriterier × 3 niveauer)

Bedøm den faglige forståelse og begrundelse — ikke antallet af kommandoer.

| Kriterium | Utilstrækkeligt (1-2 point) | Tilstrækkeligt (3-4 point) | Fremragende (5 point) |
|---|---|---|---|
| 1. Identifikation af sikkerhedsproblemer | <3 problemer eller forkerte | 3 korrekte problemer | 3+ problemer incl. ikke-åbenlyse (logging/backup), med hvor de findes |
| 2. Risikovurdering og prioritering | Ingen risiko-vurdering | Risiko nævnt for nogle problemer | Klar prioritering med konsekvens for forretningen (PII-læk, nedetid) |
| 3. Korrekte sikkerhedstiltag | Tiltag uden sammenhæng til problemerne | Tiltag passer overvejende til problemerne | Tiltag teknisk korrekte (pg_hba first-match, least privilege, TLS) og komplette |
| 4. Praktisk demonstration og verifikation | Påstår det virker uden test | Én positiv test | Både positive og negative tests kør og vist |
| 5. Faglig begrundelse og dokumentation | Uforståelig aflevering | Skabelon udfyldt, forståelig | Klar, kort, fagligt korrekt; tilbageværende risici beskrevet |

Samlet: 5-10 = ikke bestået, 11-18 = bestået, 19-25 = fremragende.
